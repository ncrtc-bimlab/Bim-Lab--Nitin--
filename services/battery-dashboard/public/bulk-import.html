Services / Bulk add LoRaWAN sensors

Bulk add LoRaWAN sensors

Choose the ChirpStack device profile and application, then import sensor details from an Excel workbook. This importer creates LoRaWAN devices only.

1

Select a device profile

Choose the LoRaWAN profile to assign to every sensor in this workbook.

2

Select an application

All imported devices will be created inside this application.

3

Upload and review the Excel file

Use the import template to keep the required column names and text formatting.

Required columns: DevEUI, App Key, Asset ID/Name. JoinEUI and Description are optional. EUIs and keys must be text; App Key is 32 hexadecimal characters. NwkKey is required for LoRaWAN 1.1 profiles.
